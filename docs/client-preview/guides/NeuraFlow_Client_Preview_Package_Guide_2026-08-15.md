# NeuraFlow Client Preview Package Guide

## Recommended presentation order

1. `NeuraFlow_Product_Opportunity_Radar_Service_Overview_2026-08-15.pdf` — explain the service, weekly outputs, selection method and price.
2. `NeuraFlow_Product_Opportunity_Brief_Illustrative_2026-08-15.pdf` — show the mobile-friendly weekly decision briefing.
3. `NeuraFlow_Product_Opportunity_Evidence_Illustrative_2026-08-15.xlsx` — trace one opportunity through Shortlist, Evidence and Supplier Leads.
4. `NeuraFlow_Monthly_Service_Offer_2026-08-15.pdf` — close with the exact monthly scope, price, delivery and next step.

## Client-shareable files

- `NeuraFlow_Product_Opportunity_Radar_Service_Overview_2026-08-15.pdf`
- `NeuraFlow_Product_Opportunity_Brief_Illustrative_2026-08-15.pdf`
- `NeuraFlow_Product_Opportunity_Evidence_Illustrative_2026-08-15.xlsx`
- `NeuraFlow_Monthly_Service_Offer_2026-08-15.pdf`

The report, workbook and brochure sample-output page state that the preview uses sample data.

## Internal-only file

- `NeuraFlow_Client_Demo_Walkthrough_2026-08-15.md`

Do not send source data, HTML or CSS, scripts, production plans, manifests, review images, validation logs, credentials, provider pricing, internal cost limits or time assumptions.

## Application boundary

Do not begin application development because the prospect liked the presentation. Proceed only after written acceptance of the scope and price, preferably with first-month payment or another clear paid commitment. Final branding, the start date and any required access must also be ready.
